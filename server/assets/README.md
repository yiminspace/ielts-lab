These are original demonstration assets for IELTS Lab. They contain no archived course content.

- The English prompts and lesson text are authored in `../demo.mjs` and `demo-transcript.txt`.
- WAV files were rendered locally with macOS's Samantha system voice, then converted to mono 22,050 Hz PCM with FFmpeg. They are included so the demo also works on other operating systems without a speech engine.
- `demo-listening.wav` concatenates four independently rendered utterances; its timeline in `demo.mjs` follows those boundaries.
- `demo-slide.svg` is an original vector slide.

These files are used only in demo mode. Imported study media stay in the user's archive folder and are never copied into this repository.

`demo-course.mp4` is an original solid-color practice slide rendered with FFmpeg, using the original demo listening narration. It exists to exercise local video playback, seeking, and the course interface.
