# IELTS Lab · 雅思练习室

个人本地雅思练习应用。把自己已有的材料整理为可交互的听力、阅读、词句和口语写作练习，独立保存草稿、收藏、笔记和练习结果。

应用代码与资料分开：仓库只包含原创实现、原创示例与测试。不会上传个人题库、音视频、账号令牌或练习记录。

## 运行

需要 Node.js 22.19 或以上。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:4317`）。没有导入资料时使用原创示例。

### 连接本地归档

选择包含 `data/整理` 和 `data/media` 的归档根目录：

```sh
npm run import -- /absolute/path/to/archive
npm run dev
```

导入保存目录配置，直接读取现有媒体，不额外复制数 GB 的音视频。配置和索引放在 Git 忽略的本地位置。归档目录必须保留；移动后重新导入。

### 构建与运行

```sh
npm test
npm run build
npm start
```

应用默认只监听当前电脑。网页适配手机屏幕，但这不等于手机已经能远程访问当前电脑；远程访问需要另行配置受保护的部署方式。

## 功能

- 听力：答题、题号导航、提交判分、解析、原文和译文、倍速、逐句播放与循环。
- 阅读：原文与题目分栏，填空/选择/判断/匹配，标注、译文、解析、草稿。
- 词汇与句子：发音、卡片、拼写听写、答案对照、静态语法分析。
- 数字与打字：听写核对、输入练习和完成记录。
- 口语：题目播音、计时、浏览器录音、回听和下载。
- 写作：题目、编辑器、字数、计时、草稿与导出。
- 公开课：本地视频/音频与课件图片。
- 资料管理：分类、资料集筛选、搜索、收藏。
- 学习记录：本机持久化、错题练习入口、学习笔记、JSON 备份与恢复。

具体已验证范围和边界见 [功能与验证](docs/coverage.md)。

## 数据与记录

原归档为只读。浏览器和本地服务保存练习记录；可在“资料与设置”导出备份。录音以浏览器录音功能产生，需主动下载保留。浏览器需要授予麦克风权限，且运行环境必须支持 `MediaRecorder`。

归档字段缺失时显示缺失提示。客观题判分按归档标准答案实现；同义表达、特殊答案容错与人工评分不保证与原平台完全一致。写作与口语不产生虚构 AI 分数。

## 实现

React + TypeScript + Vite；本地 Node HTTP 服务负责目录、材料、媒体范围请求和原子保存学习记录。富文本经过 DOMPurify 清理。媒体只从指定归档目录提供，不代理远程地址。

REA 的已有分析结果用于理解 Electron 客户端边界；材料字段、题型与前端可见行为用于确定实现。REA 不会恢复原平台服务器、模型、真人服务或未取得的内容。

## 开发约定

不要把真实材料或用户记录添加到测试夹具。所有可提交示例应为自行编写。`config.local.json`、`.local/`、环境文件、媒体与构建结果不应进入 Git。
