# 功能与验证

这是独立实现的个人学习应用，重建已有资料可以支撑的交互。它不是原平台服务的镜像。

## 实现依据

本地材料结构显示：

| 内容          | 已有字段依据                                                 | 使用方式                         |
| ------------- | ------------------------------------------------------------ | -------------------------------- |
| 听力/阅读题组 | `questions[].questionJson`、`answerJson`                     | 渲染题型、标准答案与解析         |
| 听力分句      | `listenDetailList` 或 LRC `listenDetail`                     | 原文译文、句子起止时间、逐句播放 |
| 阅读文章      | `passagesContent`、`articleTranslation`                      | 英文原文、可用时显示翻译         |
| 答案定位      | `positionSentence`、`sentenceList`、`articleSourceHighlight` | 显示定位依据与原文关联           |
| 词汇/句子     | `headWord`、`sentenceText`、`translations` 等                | 卡片、听写、例句                 |
| 静态语法      | `grammarTags.words`、`clauseStructure`                       | 展示已有分析                     |
| 音视频        | `localMedia` 映射                                            | 独立本地播放器                   |

对当前归档的题型盘点识别到五类题组：填空、单选、多选、判断和匹配。不同题型的组合得分与大小写/空白容错需有独立测试。界面不会根据没有提供的标准答案编造结果。

## 验收分层

1. 代码构建与纯逻辑测试。
2. 本地服务对实际归档的索引、材料解析与媒体范围请求验证。
3. 用原创示例进行浏览器交互验收，记录页面、判分、持久化和屏幕适配结果。

浏览器测试示例通过不能证明每一份历史题目的排版都正确；所有原题逐题人工比对也尚未完成。

## 明确边界

- 当前原归档排除了训练营，不扩展原账号的内容权限。
- 词汇发音、部分阅读翻译和历史练习详情存在原始缺失，应用保留缺失提示。
- 完整口语范文、写作批改和服务端评分模型没有从客户端恢复。
- 不实现会员购买、真人督学、原平台社交聊天和原平台账号体系；AI 主题交流见下方听后练习记录。
- 新内容不自动从原平台抓取；已有归档只读导入。
- 本机记录与在线 PostgreSQL 记录使用不同保存机制；在线授权、同步和部署边界见本文服务模式记录。新增听后练习已部署，生产验证记录见本文末尾。
- 音频实际输出设备、麦克风权限与每个浏览器的媒体行为仍取决于运行环境。

AI 服务、题型兼容回归及账户同步的当前实现和验证状态见本文后续记录。G 类整套计时流程与其验证边界也分别记录。

学习模式草稿在答案、标记、标注和交卷状态改变时保存，计时另以 15 秒周期和离开页面事件保存；每秒计时不会触发 `saveDraft`。浏览器重开可恢复草稿，并从最后保存的已用时继续计时；音频不会自动播放。

## IDP 参考机考界面（2026-10-18）

进入听力、阅读或写作材料，选择“进入机考界面”。学习模式与机考模式使用独立草稿；复盘仍进入原学习模式，以查看解析和原文定位。

- 听读：英文平面布局、Part 指示、底部题号与待复查标记、交卷检查页。阅读原文和问题独立滚动，可用拖动或键盘调整分栏；听力单次播放，只提供音量控制。
- Options：对照实际打开的官方听力演示实现 Contrast 和 Text size；三种对比度与三档字号。笔记、高亮与匹配拖放是功能近似，未逐项确认官方细节。
- 写作：题目与编辑器分栏、实时字数、关闭浏览器拼写检查/自动纠错、原生复制粘贴、笔记、交卷确认、正文导出。没有自动作文评分。
- 默认不计时，可选单篇限时；截止时间保存为绝对时间，刷新不延长，到时停止输入并提交。听力刷新恢复需要主动继续播放。
- 机考草稿采用版本比较；支持 Web Locks 的浏览器同时串行化同题写入。检测到其他窗口更新后停写并提示恢复，写作还可以先导出本页内容。未声称支持跨设备并发编辑。

### 与完整考试的差距

单篇入口保留一个听力 part、一篇阅读或一个写作 task 的练习；新增 G 类整卷入口已连接听力四部分、阅读三部分与两题写作共用 60 分钟的流程，详见本文末节。原材料的页级划分与部分题型排版仍需逐题校对。阅读布局参照官方说明和播放器导航；本轮进一步实看官方写作演示，补齐可调分栏和切题位置。尚未完成全部阅读/写作状态的逐像素对照。

官方熟悉测试本身与正式考试的计时、高亮和笔记存在差异，因此不能保证与所有考点及软件版本完全一致。公开前端分析的资源、散列与范围见 [参考分析](reference-analysis.md)。

## G 类整卷流程（2026-10-18）

### 已实现范围

“G 类完整套卷”位于 `#/papers`，单套入口为 `#/paper/:id`。本地 API 提供 `GET /api/papers` 与 `GET /api/papers/:id`；详情沿用经过清理的材料接口结构，公开试卷 ID 为哈希，不暴露原始请求参数或账号数据。

- 听力：4 个部分的题目可切换，音频按其真实关联顺序播放；切题不改变播放位置。四段全部结束后开始 120 秒检查期。刷新恢复保留音频部分与位置，需要主动继续播放；音频加载失败不跳过该段。
- 阅读：3 部分共用一个 60 分钟截止时间，按材料分隔答案键，避免同名题号互相覆盖。可以切换文章、题目、待复查标记与交卷页。
- 写作：Task 1 书信与 Task 2 议论文共用一个真实 60 分钟计时器；两题正文和笔记分别保存，切换及刷新不延长时间。提交或到时后保存两条写作记录，没有自动考官评分。
- 整卷状态：按 Listening → Reading → Writing 推进。每科写入完成记录后再进入下一科；同一轮练习重载时恢复阶段与原截止时间，重复完成回调不会再推进一次。机考保存使用同源共用 Web Lock 与草稿版本比较。
- 交卷结果：汇总听读客观题得分、两篇作文、分科提交原因与用时；支持返回每个部分查看作答、导出本次记录及开启新一轮练习。不换算官方 Band 分数。

### 归档完整性与原创短样例

只读关联沿用“明确命名的培训类目录 → 试卷 ID → 已归档听力/阅读/写作列表响应 → 对应材料 ID”。不按册号、相似标题或部分编号从其他试卷补齐缺项。

当前归档确认 56 套 G 类试卷，对应 224 个听力引用、168 篇阅读和 112 个写作任务。55 套通过唯一关联、4/3/2 顺序、听读各 40 分及本地音频存在检查。C8 · Test B 的阅读结构计为 42 分，保留异常说明，不能启动整卷。这里的“可启动”是结构和资源检查结果，不表示 55 套均已做人工浏览器验收。

每次套卷 API 请求都会重新检查听力文件是否存在且仍在允许目录内；文件删除或符号链接指向目录外时，原先可启动的套卷也会变为不可启动。题库范围仍为 1,630 个归档材料加 7 项原创 G 类练习，媒体允许集仍为 35,666，不把分类目录封面或原始请求响应加入媒体服务。

另有 `original-general-flow-demo` 原创短流程样例，归档模式和演示模式都可使用。它有 4 个独立听力部分引用，但四段重复同一段约 17 秒的原创录音，合计 16 题；三个阅读部分合计 18 题；写作包含一封正式书信和一篇议论文。样例以 `shortDemo: true` 明确标识，不适用完整试卷的 40 题门槛；阅读与写作仍各共用 60 分钟。4 个样例听力材料只服务此流程，不重复增加资料目录计数。

### 多行原文引用的生成失败修复（2026-10-28）
