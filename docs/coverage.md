# 功能与验证

这是独立实现的个人学习应用，重建已有资料可以支撑的交互。它不是原平台服务的镜像。

## 实现依据

本地材料结构显示：

| 内容 | 已有字段依据 | 使用方式 |
| --- | --- | --- |
| 听力/阅读题组 | `questions[].questionJson`、`answerJson` | 渲染题型、标准答案与解析 |
| 听力分句 | `listenDetailList` 或 LRC `listenDetail` | 原文译文、句子起止时间、逐句播放 |
| 阅读文章 | `passagesContent`、`articleTranslation` | 英文原文、可用时显示翻译 |
| 答案定位 | `positionSentence`、`sentenceList`、`articleSourceHighlight` | 显示定位依据与原文关联 |
| 词汇/句子 | `headWord`、`sentenceText`、`translations` 等 | 卡片、听写、例句 |
| 静态语法 | `grammarTags.words`、`clauseStructure` | 展示已有分析 |
| 音视频 | `localMedia` 映射 | 独立本地播放器 |

对当前归档的题型盘点识别到五类题组：填空、单选、多选、判断和匹配。不同题型的组合得分与大小写/空白容错需有独立测试。界面不会根据没有提供的标准答案编造结果。

## 验收分层

1. 代码构建与纯逻辑测试。
2. 本地服务对实际归档的索引、材料解析与媒体范围请求验证。
3. 用原创示例进行浏览器交互验收，记录页面、判分、持久化和屏幕适配结果。

浏览器测试示例通过不能证明每一份历史题目的排版都正确；所有原题逐题人工比对也尚未完成。

## 明确边界

- 当前原归档排除了训练营，不扩展原账号的内容权限。
- 词汇发音、部分阅读翻译和历史练习详情存在原始缺失，应用保留缺失提示。
- 完整口语范文、写作批改和服务端评分模型没有从客户端恢复。
- 不实现会员购买、真人督学、聊天和原平台账号体系。
- 新内容不自动从原平台抓取；已有归档只读导入。
- 学习记录由本地服务保存；没有完成公网部署或跨设备账户同步。
- 音频实际输出设备、麦克风权限与每个浏览器的媒体行为仍取决于运行环境。

后续可独立增加自选 AI 服务、完整套卷计时、题型逐题兼容回归及带身份验证的多设备同步。

- 浏览器使用可提交的原创示例：听力输入与交卷得到预期 3/4，错题复盘恢复当次答案；阅读判断、单选、多选和匹配全部操作后得到 9/9。
- 浏览器确认逐句选择、循环和译文切换；媒体元素实际进入播放状态，当前时间推进且无解码错误。课程生产构建的视频播放与纯音频切换也通过。

- 未使用麦克风录制实际用户语音；未逐题核对全部真题排版，也未完成手机真机验收。没有声称与原平台像素级或评分完全一致。

## 听读题型适配审计

对本机已导入归档执行 `node scripts/audit-archive.mjs`（也可显式传归档根目录）后的结构结果：

- 644 篇听力/阅读，共 1,486 组题、7,682 个计分点。
- 五类题组：519 填空、215 单选、147 多选、206 判断、399 匹配。
- 标准答案回填的判分一致性检查通过；其中 1 题标准答案的多重分隔结构存在歧义，明确标记为人工核对，不自动给分。
- 918 组填空/匹配中，917 组可将答题框放回原文空格；1 组原始空格数量和答案结构不一致，保留题干并采用下方独立答题框，显示核对提示。
- 272 篇听力均识别出分句时间轴；末句没有明确终止时间时使用音频时长，元数据未加载前使用临时结束边界。

判分规则区分单选的零起始索引、多选的无序集合与每个答案的分值；多选不允许超量勾选或通过重复选项刷分。填空接受标准答案提供的 `/` 备选及一个 `|` 的双部分交换，规范化大小写、空白和 Unicode 标点，不擅自增加同义词。解析与原文定位只使用现存字段。匹配目前以可键盘操作的选择框实现，尚未实现原版的拖拽操作；全套模拟考和逐题人工视觉验收不在本次已验证范围。

草稿在答案、标记、标注和交卷状态改变时保存，计时另以 15 秒周期和离开页面事件保存；每秒计时不会触发 `saveDraft`。浏览器重开可恢复草稿，并从最后保存的已用时继续计时；音频不会自动播放。
